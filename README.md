# React On-Screen Keyboard

An accessible React on-screen keyboard with optional physical keyboard support using Hooks 

## Project Background

This keyboard began as a component for a collaborative Wordle-style application during a Chingu Voyage. I've refactored and expanded it into a standalone React component to improve its architecture, usability, and feature set. 

## Features

- Interactive on-screen keyboard
- Optional physical keyboard support
- Dynamic keyboard layout rendered from arrays
- React Hooks (`useState`, `useEffect`)
- Global keyboard event listeners with proper cleanup
- Responsive and accessible interface

## Built With

- React
- JavaScript (ES6+)
- CSS3
- Vite
